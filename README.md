# man-translate

Утилита для перевода man-страниц GNU/Linux на русский язык с помощью
LLM, с установкой перевода в систему и хранением переводов в git-репозитории.

Скрипт **не переводит сам** — он готовит текст для передачи в LLM
(ChatGPT, Claude и т.п.), проверяет результат, устанавливает его в
систему и сохраняет в репозиторий, чтобы переводы не терялись при
переустановке системы или смене компьютера.

---

## Возможности

- Подготовка man-страницы к переводу: распаковка, добавление промпта
  и служебных разделителей.
- Поддержка сжатых страниц: `.gz`, `.xz`, `.bz2`, `.zst`.
- Проверка результата: контроль изменения файла, проверка на остатки
  служебных разделителей, валидация roff через `groff`.
- Установка перевода в `/usr/local/share/man/ru/manN/` и обновление
  базы `mandb`.
- Сохранение несжатого перевода (чистый roff) в git-репозиторий.
- Автоматический (по запросу) `git commit` и `git push`.
- Массовая установка готовых переводов из репозитория при
  разворачивании на новой машине.

## Установка

```sh
git clone https://github.com/mirninec/man-translate.git man-translate
cd man-translate
./install.sh
```

`install.sh`:

1. Устанавливает программу в `/usr/local/bin/man-translate`.
2. Устанавливает промпт в `/usr/local/share/man-translate/prompt.txt`.
3. Предлагает записать путь к репозиторию в конфиг
   (см. «Настройка репозитория»).
4. Если в репозитории есть готовые переводы — предлагает установить
   их в систему (см. «Восстановление переводов»).

## Настройка репозитория

Чтобы установленная команда `man-translate` знала, куда сохранять
переводы, ей нужен путь к клону этого репозитория.

Путь определяется по приоритету:

1. Переменная окружения `MAN_TRANSLATE_REPO`.
2. Строка `REPO=...` в `~/.config/man-translate/config`.
3. Каталог `translations` рядом со скриптом
   (актуально только при запуске `./man-translate.sh` из клона
   до установки).

### Автоматическая настройка

При запуске `./install.sh` скрипт предложит записать путь к текущему
репозиторию в `~/.config/man-translate/config`. Это рекомендуемый
способ: он не зависит от shell и не требует перезапуска сессии.

### Ручная настройка

Через конфиг:

```sh
mkdir -p ~/.config/man-translate
echo "REPO=$HOME/man-translate" > ~/.config/man-translate/config
```

Либо через переменную окружения (например, в `~/.bashrc`):

```sh
export MAN_TRANSLATE_REPO="$HOME/man-translate"
```

Переменная окружения имеет наивысший приоритет и удобна для
временного переопределения репозитория.

## Использование

```sh
man-translate <сущность>
```

Примеры:

```sh
man-translate scp
man-translate printf
man-translate rpc
```

### Пошаговый процесс

1. Скрипт находит английскую man-страницу и определяет её имя и
   раздел.
2. Создаёт файл `~/man-ru-translate/<имя>.<раздел>.ru`, содержащий
   промпт, разделители и оригинальный roff-текст.
3. Вы открываете файл, копируете его содержимое, передаёте LLM.
4. **Полностью заменяете** содержимое файла ответом LLM
   (без промпта и без разделителей) и сохраняете файл.
5. Нажимаете ENTER. Скрипт:
   - проверяет, что файл изменился;
   - проверяет отсутствие служебных разделителей;
   - валидирует roff через `groff`;
   - сжимает и устанавливает страницу в систему;
   - сохраняет несжатый перевод в репозиторий;
   - предлагает закоммитить и запушить изменения;
   - обновляет базу `mandb`.

Проверка результата:

```sh
LANG=ru_RU.UTF-8 man <сущность>
```

### Прочие флаги

```sh
man-translate --help      # справка
man-translate --version   # версия
```

## Хранение переводов

Переводы хранятся в репозитории в каталоге `translations` в
**несжатом** виде (чистый roff). Это удобно для git: диффы читаемы,
переводы легко просматривать и поддерживать.

Структура:

```
translations/
└── ru/
    ├── man1/
    │   ├── scp.1
    │   └── wc.1
    └── man5/
        └── rpc.5
```

Раздел определяется по имени каталога `manN`, а имя файла — как
`<имя>.<раздел>` без сжатия.

> Пустой каталог `translations/` можно зафиксировать в git с помощью
> файла-заглушки `translations/.gitkeep`. Он не мешает: логика поиска
> переводов рассматривает только файлы внутри `translations/<язык>/manN/`.

## Коммит и публикация переводов

После сохранения перевода в репозиторий `man-translate` предлагает:

```
Закоммитить и запушить изменения? (y/N):
```

При согласии скрипт:

- добавляет в индекс **только** файл нового перевода
  (не `git add .`, чтобы не захватить посторонние правки);
- создаёт коммит с сообщением
  `Add translation: <имя>.<раздел>`;
- выполняет `git push`.

Если `git` не установлен, каталог не является git-репозиторием, или
вы ответили «нет» — скрипт выведет команды для ручного выполнения.

Ошибки `push` (нет remote, нет сети, требуется аутентификация) не
прерывают работу: страница уже установлена и сохранена, а push можно
повторить вручную:

```sh
git -C "$HOME/man-translate" push
```

## Восстановление переводов на новой машине

При переустановке системы или на новом компьютере:

```sh
git clone https://github.com/mirninec/man-translate.git man-translate
cd man-translate
./install.sh
```

Если в репозитории есть каталог `translations` с переводами,
`install.sh`:

1. Покажет список найденных переводов.
2. Спросит подтверждение на установку.
3. Для каждого перевода проверит roff, сожмёт его и установит в
   `/usr/local/share/man/ru/manN/`.
4. Один раз обновит базу `mandb`.

Битые страницы (не проходящие проверку `groff`) пропускаются и не
ломают систему `man`; в конце выводится сводка «установлено /
пропущено».

## Настройка промпта

Промпт для LLM выбирается по приоритету:

1. Пользовательский: `~/.config/man-translate/prompt.txt`
2. Рядом со скриптом: `<репозиторий>/prompt.txt`
3. Системный: `/usr/local/share/man-translate/prompt.txt`
4. Встроенный запасной (если ничего не найдено).

Чтобы использовать собственный промпт, поместите его в:

```
~/.config/man-translate/prompt.txt
```

Промпт по умолчанию инструктирует LLM сохранять разметку roff, не
переводить команды, опции, пути, переменные и код, а также
переводить стандартные заголовки разделов
(`NAME → ИМЯ`, `DESCRIPTION → ОПИСАНИЕ` и т.д.).

## Типичный рабочий цикл

```sh
# 1. Перевод и установка
man-translate wc
#    ... перевод через LLM, ENTER ...
#    ... "Закоммитить и запушить изменения? (y/N):" -> y

# 2. На другой машине — восстановление
git clone <URL> man-translate
cd man-translate
./install.sh
#    ... "Установить эти переводы в систему? (y/N):" -> y

# 3. Проверка
LANG=ru_RU.UTF-8 man wc
```
